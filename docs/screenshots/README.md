# Скриншоты

Папка для скриншотов приложения. Сейчас пустая — файлы не закоммичены, поэтому
картинки в корневом README пока не отрисуются (это ожидаемо, не ошибка сборки).

## Что положить сюда

| Файл                | Что на нём                                    | Используется в            |
|---------------------|-----------------------------------------------|---------------------------|
| `01-input.png`      | Галерея роликов: сетка превью, отметки, папка  | README, F-Droid           |
| `02-edit.png`       | Правка: сетка движков + «Сравнение качества»   | README, F-Droid           |
| `03-compare.png`    | Сравнение трёх уровней: плеер + слайдер       | README, F-Droid           |
| `04-output.png`     | Вывод: очередь, выполненные, экономия         | README, F-Droid           |
| `icon-512.png`      | Иконка 512×512 (feature graphic для F-Droid)  | README                    |

## Требования

- Снимать с реального устройства, портрет, без статус-бара с личным содержимым.
- Ширина 1080 px (или 1440). В README они вставятся как `<img width="280">`.
- Имена — только те, что выше, иначе ссылки в README/F-Droid-метаданных разъедутся.
- Всё это попадает в репозиторий: для F-Droid скриншоты обязательны, без них
  сборку не примут.
