## [0.1.0] — 2026-10-13

Первый публичный релиз.

### Ввод
- Галерея роликов: сетка превью без подписей, группировка по датам, кэш обложек.
- Мультивыбор: тап ставит отметку с порядковым номером, первый отмеченный идёт
  на сравнение качества.
- Импорт пачки: кнопка «Импорт: N» отправляет остальные отмеченные ролики
  в очередь с текущим уровнем качества.
- Выбор папки ввода: галерея листает выбранное дерево SAF (например, только
  Downloads) — разрешение на доступ к медиа тогда не требуется.
- Ручной мультипикер через SAF для файлов вне MediaStore.

### Правка
- Четыре движка: MediaCodec H.264 / H.265, libx264, MPEG-4. Сетка 2×N с
  короткими именами; недоступные в сборке помечены «нет в сборке».
- Сравнение трёх уровней (Высокое / Баланс / Эко) на реальном 10-секундном
  отрезке из середины файла, с прогрессом и отменой.
- Плеер превью (Media3 ExoPlayer): переключение уровня сохраняет позицию,
  полноэкранный режим, соотношение сторон по реальному кадру.

### Вывод
- Очередь в фоновом ForegroundService: уведомление с прогрессом и кнопкой
  «Стоп», кодирование переживает сворачивание приложения.
- Выполненная очередь: что пережато, было → стало, экономия в МБ и процентах.
- Папка вывода: app-specific по умолчанию или любая папка хранилища (SAF).
- Журнал ffmpeg под кнопкой, с копированием в буфер.

### Прочее
- Три экрана со свайпом и парящим док-баром, тёмная тема в духе HandBrake.
- Только arm64-v8a, minSdk 24, сборка движка вкомпонована в APK (~31 МБ).
- Сборка APK по тегу `v*` через GitHub Actions, подпись релизным ключом
  разработчика из Secrets.
- Формат размеров и таймкодов больше не зависит от языка системы: раньше на
  английской локали «31,3 МБ» показывалось как «31.3 МБ».

## Разработка ведётся в ветке `dev`, релиз собирается из `release`.
`dev` → `release` → тег `vX.Y.Z` → GitHub Actions → APK в Releases.
