## [0.1.1] — 2026-10-14

Переработанный ввод и стеклянный док. Обновление ставится поверх 0.1.0
(подпись тем же ключом).

### Исправлено
- Ролики со звуковой дорожкой падали с «Ошибка чтения: d != java.lang.String»:
  в строке `stream_audio` частота дискретизации была объявлена как `%d`, а
  ffmpeg-kit возвращает её строкой. Теперь `%s`, плюс класс исключения и
  стектрейс в журнале вместо голого сообщения.
- Просмотр ролика из карточки отбора падал с «Failed to open SAF id»:
  SAF-URL освобождался до чтения. Освобождение перенесено в `finally` после
  чтения.
- Кнопка «Импорт» выглядела мёртвой: очередь пополнялась, а на экране «Ввод»
  ничего не менялось. Кнопки «Импорт» больше нет (см. ниже).
- Белый экран при запуске: системная тема была `Material.Light`, окно
  рисовалось белым до первого кадра Compose. Теперь тёмная тема с фоном
  цвета палитры.

### Ввод — новая схема
- Сетка во весь экран: 4 плитки в ряд, без полей и скруглений, тонкие
  разделители. Шапка плавает поверх, пилюля навигации — тоже.
- Вид сетки переключается шестерёнкой: ровная сетка или разбивка по датам.
- Отметка — это просто «взять в обработку», без первого/второго. Кнопки
  «Импорт» нет: все отмеченные уходят в очередь с «Правки» и «Вывода»,
  снимаются сами после успешного кодирования или кнопкой «Сбросить отметки».
- Карточка отбора над доком: «Выбрано N роликов · общий размер X МБ» плюс
  карусель превью. Тап открывает полноэкранный слой: крупные превью три
  в ряд, галочка снимает отметку, тап по превью — плеер исходника и те же
  метаданные ffprobe, что у входа сравнения.
- Размер в карточке — из `MediaStore.SIZE` / `COLUMN_SIZE`, без опроса
  каждого файла. Где провайдер размер не отдаёт — «размер неизвестен».
- Папка через SAF: обложки больше не серые — при пустом `loadThumbnail`
  кадр декодируется через `MediaMetadataRetriever`, сразу в размере плитки.
  Кэш обложек ограничен байтами (12 МБ), неудачи тоже кэшируются.
- Производительность сетки: предзагрузка на 3 строки вперёд и 1 назад,
  декодирование не запускается во время прокрутки — только после остановки.

### Правка
- Ролик для сравнения выбирается кнопкой «Сравнить 3 уровня» из отмеченных
  на «Вводе»: одно нажатие по плитке отправляет ролик на три уровня,
  кнопка «i» открывает техподробности.
- Под кнопкой сравнения — строка состояния отбора («Выбрано N · общий
  размер»), кнопка «В очередь» берёт всю отметку целиком.

### Оформление
- Стеклянный док (Haze 1.5.4): размытие контента под пилюлей внутри той же
  композиции. Системный `FLAG_BLUR_BEHIND` в отдельном окне не подошёл —
  прошивка его игнорирует. Ограничение платформы: `SurfaceView` плеера
  в блюр не попадает. Подробности — `docs/DOCK_BLUR.md`.
- Карточка отбора — то же стекло, чуть темнее дока.
- Пустое состояние «Ввода» больше не уезжает под док.

### Сборка
- Включён R8 (`optimization.enable`): APK 31,3 → ~19 МБ, `classes.dex`
  47 → 2,8 МБ распакованных. На диске после установки ~28 МБ вместо 80 МБ.
  Свои keep-правила — в `app/src/main/keepRules/*.keep`.

## [0.1.0] — 2026-10-13

Первый публичный релиз.

### Ввод
- Галерея роликов: сетка превью без подписей, группировка по датам, кэш обложек.
- Мультивыбор: тап ставит отметку с порядковым номером, первый отмеченный идёт
  на сравнение качества.
- Импорт пачки: кнопка «Импорт: N» отправляет остальные отмеченные ролики
  в очередь с текущим уровнем качества.
- Выбор папки ввода: галерея листает выбранное дерево SAF (например, только
  Downloads) — разрешение на доступ к медиа тогда не требуется.
- Ручной мультипикер через SAF для файлов вне MediaStore.

### Правка
- Четыре движка: MediaCodec H.264 / H.265, libx264, MPEG-4. Сетка 2×N с
  короткими именами; недоступные в сборке помечены «нет в сборке».
- Сравнение трёх уровней (Высокое / Баланс / Эко) на реальном 10-секундном
  отрезке из середины файла, с прогрессом и отменой.
- Плеер превью (Media3 ExoPlayer): переключение уровня сохраняет позицию,
  полноэкранный режим, соотношение сторон по реальному кадру.

### Вывод
- Очередь в фоновом ForegroundService: уведомление с прогрессом и кнопкой
  «Стоп», кодирование переживает сворачивание приложения.
- Выполненная очередь: что пережато, было → стало, экономия в МБ и процентах.
- Папка вывода: app-specific по умолчанию или любая папка хранилища (SAF).
- Журнал ffmpeg под кнопкой, с копированием в буфер.

### Прочее
- Три экрана со свайпом и парящим док-баром, тёмная тема в духе HandBrake.
- Только arm64-v8a, minSdk 24, сборка движка вкомпонована в APK (~31 МБ).
- Сборка APK по тегу `v*` через GitHub Actions, подпись релизным ключом
  разработчика из Secrets.
- **Английский язык интерфейса.** Весь текст вынесен в ресурсы, добавлен выбор
  языка в настройках Android 13+. Раньше весь текст был зашит в код по-русски:
  подписи перечислений, уведомления и журнал. Добавление языка — копия папки
  `res/values-en` в `res/values-xx`.
- Числа и единицы размера следуют за языком интерфейса: раньше на английской
  локали «31,3 МБ» показывалось как «31.3 МБ».
